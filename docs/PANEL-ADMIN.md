# Panel controlador — Salfate Abogados

Panel en **https://www.salfateabogados.cl/panel**

## Para el estudio (uso diario)

1. Entra con la contraseña
2. Usa el menú lateral (Controlador, Contacto, Inicio, etc.)
3. Edita textos
4. Revisa la **vista previa**
5. Opcional: **Revisar ortografía**
6. **Guardar y publicar** (la web se actualiza en 1–2 minutos)

### Asistente IA
En **Asistente IA** puedes preguntar cómo editar secciones.  
Si hay un error o necesitas ayuda, usa **Reportar error** / **Pedir ayuda**: se notifica a **carlos.salfate@chileatiende.cl**.

## Qué se puede editar
Contacto, inicio, audiencia, especialidades, metodología, FAQ, formulario, chat, SEO/tema, pie y CTA.
